title: 交互式 TUI
description: "探索项目、修改代码、审查结果，并在之后继续工作"
---

在 TUI 中，你可以和 Ante 一起完成任务：提出问题、添加上下文、审查修改，并决定下一步。

在项目目录中打开终端并运行：

```bash
cd your-project
ante
```

首次使用时，请先[连接提供商](/usage/providers)，然后发送提示词。

## 探索不熟悉的项目 {#explore-an-unfamiliar-project}

先提出一个范围明确的问题：

```text
解释这个项目如何启动。找到主要入口，并追踪请求如何到达数据库。
```

输入消息并按 `Enter`。Ante 会流式显示回答，以及过程中使用的文件和命令。可以继续在同一对话中追问，缩小调查范围。

要指定某个文件，输入 `@` 并从补全菜单中选择：

```text
解释 @src/main.rs，并说明它依赖哪些模块。
```

也可以引用文件夹、粘贴截图或提供网址。相关流程请参阅[提供上下文](/usage/providing-context)。

## 修改代码并审查结果 {#make-a-change-and-review-it}

告诉 Ante 明确的目标和约束：

```text
配置文件缺失时，显示清晰的错误消息。保留现有 CLI 行为，并运行相关测试。
```

1. **明确任务。** Ante 提问时，可以选择选项，或使用 **Chat about this** 进一步解释需求。
2. **审查请求的操作。** 工具需要授权时，按 `Tab` 查看拟议的 diff 或命令详情。可以批准、拒绝，或拒绝并说明应如何调整。
3. **检查结果。** 当前轮次结束后，运行 `/diff` 查看工作区修改，包括未跟踪文件。需要调整时，继续告诉 Ante。
4. **验证目标。** 请 Ante 运行相关检查，并在结束前解释失败原因。

权限选项与会话授权请参阅[审批指南](/usage/approvals)。

### 查看完整执行细节 {#transcript-view}

按 `Ctrl+O` 打开完整记录，包括主对话中折叠的工具输出和思考内容。使用 `j` / `k` 或 `PgUp` / `PgDn` 滚动，再按 `Ctrl+O` 或 `q` 返回对话。

## 在执行中调整方向 {#change-direction-while-ante-works}

如果需要补充约束，可以在 Ante 运行时输入并按 `Enter`：

```text
也处理空配置文件，并复用现有错误类型。
```

消息会进入队列。按 `Ctrl+S` 将指导立即送入当前轮次，或留在队列中等待下一轮执行。

要停止当前操作，可以在没有弹窗时按 `Escape`，或按 `Ctrl+C`。然后发送修正后的提示词；对话上下文仍然保留。示例请参阅[中断与引导](/usage/steering)。

## 自己运行命令 {#bash-mode}

以 `!` 开头可直接执行 Shell 命令：

```text
!git status
!cargo test
```

命令输出会成为下一条消息的上下文。接着输入 `解释这次失败，并修复根本原因。`，即可让 Ante 根据刚才的结果继续工作。

这些命令会在你的授权下立即运行。交互式程序请使用终端会话。

### 使用服务器或 REPL {#terminal-sessions}

请 Ante 在命名终端会话中启动开发服务器或 REPL。运行 `/term` 选择现有会话，查看或直接操作程序。再次运行 `/term <name>` 可分离查看窗口，程序仍会继续运行。

终端会话需要 `tmux`，并会在 Ante 重启后保留。完成后可通过 `/term` 选择器停止会话。启动和连接选项请参阅[终端控制](/reference/tui-reference#terminal-sessions)。

## 为下一步选择模型 {#choose-a-model-for-the-next-step}

使用 `/models` 调整当前提供商的模型或思考深度。要切换提供商，使用 `/providers`，然后在选择器中确认模型。

例如，可以先用一个模型探索代码，再在同一对话中选择另一个模型解决困难的调试问题。选择流程请参阅[模型与思考深度](/usage/models-and-thinking)。

### 查看会话用量 {#session-usage}

运行 `/usage` 查看各模型的 Token 用量、缓存使用及轮次统计。受支持的订阅还会显示额度信息。这些数据帮助你了解当前会话；账单仍以提供商控制台为准。

## 继续较长的任务 {#continue-a-longer-task}

对于有明确完成条件的任务，可以设置目标：

```text
/goal 所有测试通过，且 cargo clippy 不报告警告
```

Ante 会持续检查进展是否满足条件。使用 `/goal` 查看状态，使用 `/goal clear` 结束循环。完成与中断规则请参阅[目标会话](/usage/goal-sessions)。

对话变长时，可运行 `/context` 查看上下文大小。使用 `/compact 重点保留尚未解决的测试失败` 总结较早的工作，并保留下一步需要的信息。

### 为任务命名 {#session-title}

离开前，为对话起一个容易识别的名字：

```text
/rename 配置错误处理
```

标题会显示在恢复选择器和终端标签页中。

### 从上次进度继续 {#session-resume}

启用会话保存时（默认开启），可以通过 `/exit` 退出并在之后恢复：

1. 在同一个项目目录中运行 `ante`。
2. 输入 `/resume`，按标题或首条消息找到对话。
3. 按 `Enter`，然后发送下一条指令。

Ante 会恢复保存的对话，并使用当前权限设置。也可以直接运行 `ante --resume <SESSION_ID>`。使用 `--no-session-save` 启动的会话无法恢复。

### 接续 Claude Code 或 Codex 的工作 {#coming-from-claude-code-or-codex}

使用 `/resume-claude` 或 `/resume-codex` 接续当前项目中最近的对话。这些内置技能会读取之前的记录，梳理任务与进度，并在继续之前与你确认下一步。添加会话 ID 可选择特定对话。

## 调整终端体验 {#make-the-terminal-comfortable}

运行 `/config` 调整偏好，或使用 `/theme` 选择主题。若终端丢失内联滚动记录，可以使用 `ante --fullscreen` 启动，或在 `/config` 中修改 **Render mode**。

具体命令和控制方式请参阅[斜杠命令](/usage/slash-commands)、[快捷键](/reference/tui-reference#keyboard-shortcuts)以及 [TUI 参考手册](/reference/tui-reference)。
