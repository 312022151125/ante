title: "Coding Plans"
description: "Use third-party coding subscription plans with Ante"
---

Many model providers — including Aliyun/Qwen, MiniMax, Kimi, ByteDance/Ark, z.ai, and more — offer affordable, generous coding plans with large monthly API quotas optimized for AI coding tools. Because these plans expose standard Anthropic or OpenAI-compatible endpoints, Ante works with them out of the box.

## Ali Coding Plan

Configure Alibaba Cloud's [Coding Plan](https://help.aliyun.com/zh/model-studio/coding-plan) as a custom provider in `~/.ante/catalog.json`.

Using the Anthropic-compatible endpoint:

```json
{
  "providers": {
    "ali-coding-plan": {
      "display_name": "Ali Coding Plan",
      "base_url": "https://coding.dashscope.aliyuncs.com/apps/anthropic",
      "auth": { "bearer": { "env_key": "ALI_CODING_PLAN_API_KEY" } },
      "wire_style": "AnthropicMessage",
      "preferred_models": [
        { "id": "qwen3.5-plus", "description": "Qwen 3.5 Plus with vision", "context_limit": 1000000 },
        { "id": "qwen3.6-plus", "description": "Qwen 3.6 Plus with vision", "context_limit": 1000000 },
        { "id": "glm-5.1", "description": "GLM-5.1 model", "context_limit": 200000 },
        { "id": "MiniMax-M2.5", "description": "MiniMax M2.5 model", "context_limit": 205000 },
        { "id": "qwen3-coder-next", "description": "Qwen 3 Coder Next", "context_limit": 1000000 },
        { "id": "qwen3-coder-plus", "description": "Qwen 3 Coder Plus", "context_limit": 1000000 }
      ]
    }
  }
}
```

Some models are only available on the OpenAI-compatible endpoint:

```json
{
  "providers": {
    "ali-coding-plan-oai": {
      "display_name": "Ali Coding Plan (OpenAI)",
      "base_url": "https://coding.dashscope.aliyuncs.com/v1",
      "auth": { "bearer": { "env_key": "ALI_CODING_PLAN_API_KEY" } },
      "wire_style": "OpenAiCompatible",
      "http_headers": {
        "User-Agent": "ante-cli/1.0.0",
        "X-DashScope-UserAgent": "coding-agent"
      }
    }
  }
}
```

Run Ante with your coding plan key:

```bash
export ALI_CODING_PLAN_API_KEY="sk-sp-xxxxx"
ante --provider ali-coding-plan --model qwen3.5-plus
```

## Generic coding plans

The examples below use z.ai DevPack; other coding plans follow the same pattern.

### Anthropic-compatible

Use the `anthropic` provider with `MODEL_BASE_URL` pointing to the plan's endpoint.

**Example: z.ai DevPack**

```bash
export ANTHROPIC_API_KEY="your_z_ai_key"
export MODEL_BASE_URL="https://api.z.ai/api/anthropic"

ante --provider anthropic --model glm-5-turbo -p "refactor the auth module"
```

### OpenAI-compatible

Use the `openai-compatible` provider with `MODEL_BASE_URL` pointing to the plan's endpoint.

**Example: z.ai DevPack**

```bash
export OPENAI_COMPATIBLE_API_KEY="your_z_ai_key"
export MODEL_BASE_URL="https://api.z.ai/api/coding/paas/v4"

ante --provider openai-compatible --model glm-5-turbo -p "add unit tests for the cache layer"
```
